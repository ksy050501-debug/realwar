# 🏯 천하쟁패 (realwar)

웹 브라우저에서 바로 플레이하는 턴제 대륙 전략 시뮬레이션 게임입니다. 설치 없이 `index.html`을 열면 실행됩니다.

## 게임 목표
청룡국의 군주가 되어 대륙의 **모든 땅(100%)** 을 차지하면 천하통일!

## 주요 요소
- **내정**: 농업·상업 개발, 성벽 보수, 구휼(민심), 징병, 매복 설치
- **특화 병종**: 창병·궁병·기병·산악병·공성병 (지형에 따라 징병 가능 병종이 다름)
- **육성**: 훈련도, 지형 숙련, 전투 경험, 장수 특기
- **전술 전투**: 최대 5합, 돌격 ▶ 화살비 ▶ 방진 ▶ 돌격 상성 + 계략, 정찰 보고, 일기토, 후퇴, 날씨
- **보급**: 도읍과 이어진 영토에서만 보급, 보급대 파견, 계절(겨울 혹독·가을 추수)
- **외교**: 선물, 교역 협정, 군량 거래, 휴전, 동맹, 공물 요구, 적 장수 매수, 배신
- **격변**: 장수 이적·독립, 민란, 신흥 세력 등장, 기습 공격

## 파일
- `index.html` — 게임 본체 (단일 파일)
- `prototypes/tactics.html` — 초기 칸 단위 전술전 프로토타입
